# Sistema de Gestão de Restaurante

Aplicação desktop acadêmica para a gestão interna de um restaurante, desenvolvida com Java, JavaFX, FXML e Maven.

## Estado do projeto

O código atual é uma base funcional proveniente de um projeto anterior. Ele está sendo adaptado incrementalmente para atender aos requisitos do Projeto 06.

O escopo funcional será adaptado incrementalmente conforme as entregas da disciplina.

## Pré-requisitos

- Java 17 ou superior
- Maven, ou o Maven Wrapper incluído no projeto

## Execução

No Linux ou macOS:

```sh
./mvnw javafx:run
```

No Windows:

```bat
mvnw.cmd javafx:run
```

## Credencial de demonstração

- Usuário: `admin`
- Senha: `admin`

As credenciais e a persistência em JSON pertencem à versão inicial e serão substituídas por autenticação segura e SQLite durante a evolução do projeto.
